# RTS Graphics Lab

Эксперименты с процедурной графикой для будущей браузерной RTS. **Это не игровой проект и не готовый движок.**

## Эксперименты

| Версия | Файл | Назначение |
| --- | --- | --- |
| **v1** | [experiments/v1/index.html](experiments/v1/index.html) | **Визуальный эталон:** наиболее удачный контур Panther, несколько LOD, окраски, поворот башни |
| **v2** | [experiments/v2/index.html](experiments/v2/index.html) | Повреждения, гусеницы, свет; эксперимент сохранён независимо, хотя детализация менее удачная |
| **Volume Study** | [experiments/volume-study/index.html](experiments/volume-study/index.html) | **Отдельный тест объёма:** экструдированная геометрия, боковые грани, ортографическая камера, наклон и направленный свет |

Открыть [index.html](index.html) локально в браузере или опубликовать репозиторий через GitHub Pages.

## Обязательные правила редактирования

1. **Никогда не перерисовывать v1 с нуля при добавлении новой функции.** При улучшениях сохранять первичную геометрию и исходный HTML. Для новых функций использовать отдельную ветку/копию/модуль, сравнивать результат с исходной моделью.
2. **Не удалять v2.** Это отдельный полезный технический эксперимент.
3. **Объёмная модель отдельно от v1.** Текущий Volume Study демонстрирует геометрические высоты и свет, но не претендует на точную форму Panther; не заменять им детализированную v1.
4. При изменениях делать контрольные скриншоты с одинаковыми LOD, углом, масштабом и окраской. Регрессия геометрии — основание откатить изменение.
5. Добавлять зависимости и платные услуги только при реальной необходимости и с одобрения владельца. Пока каждый эксперимент — автономный HTML без внешних библиотек.
6. Различать: обычный плоский top-down, псевдообъём от градиентов и теней, **реальную геометрическую 2.5D/3D высоту** с видимыми боковыми гранями при наклоне камеры.
7. Разработка игры отдельно от графического полигона. Обсуждения и принятые решения фиксируются в журнале проекта.

## GitHub Pages

Для просмотра в браузере без скачивания: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

После успешной публикации главная страница обычно доступна по адресу `https://valeriykoksharov.github.io/rts-graphics-lab/`; проверяйте фактическую ссылку в разделе Pages.
